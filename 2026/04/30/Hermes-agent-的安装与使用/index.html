Hermes Agent 的安装与使用

Hermes Agent 是什么？

Hermes Agent 是由 Nous Research 开发的一款自进化 AI 助手（有内置学习循环），v0.11.0，MIT 开源协议。

它的核心特点是：会从使用经验中创建技能并持续改进，还能跨会话记住你的偏好。可以用在任何模型（OpenRouter、MiniMax、Kimi 等），支持 CLI / Telegram / Discord / WhatsApp 等多种接入方式。

支持的平台与模型

平台：Linux、macOS、Windows WSL2、Android Termux
模型接入：OpenRouter（200+ 模型）、Nous Portal、NVIDIA NIM、Xiaomi MiMo、Kimi/Moonshot、MiniMax、Hugging Face、OpenAI 等

主要功能一览

  • 自进化技能系统：复杂任务后自动创建技能，并在使用中持续改进
  • 持久记忆：跨会话记住用户偏好和知识
  • 多平台接入：Telegram、Discord、Slack、WhatsApp、Signal、Email
  • 定时自动化：用自然语言设置定时任务（如”每天早八点发报告”）
  • 子 Agent：并行派生子任务，协同完成复杂工作
  • OpenClaw 迁移：支持从 OpenClaw 一键迁移配置
